# Open Arcade game sources

The HTML games in this directory are selected, self-contained files from
[`wangzifan396-wzf/mini-browser-games`](https://github.com/wangzifan396-wzf/mini-browser-games),
retrieved on 2026-09-03. They are redistributed under the adjacent MIT `LICENSE`.

Nexus supplies only the surrounding launcher and catalog metadata. The original
game source remains attributed to its upstream author.
